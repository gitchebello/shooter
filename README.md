# Shooter

Shooter arcade 2D com visual de desenho animado antigo, inspirado em *Cuphead*: poucos inimigos, chefes grandes, textura de papel e uma faixa de tempo no topo.

## Rodar

O jogo inteiro é o `index.html`. Abra direto no navegador ou sirva a pasta:

```bash
python3 -m http.server 8000    # http://localhost:8000
```
